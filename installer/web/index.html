KiwiConvert Free file converter for Windows

Convert files where you already are.

Hold Shift while you drag a file in File Explorer. Drop it on a format in the wheel and the converted copy appears next to the original.

  • Photos, video, audio, PDFs, subtitles and archives
  • Everything runs on this PC. Nothing is uploaded.
  • Compress, trim, crop, redact, merge and more
